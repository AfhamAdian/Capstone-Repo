# version control metrics choosen for health score calculation:
* Issues Closed Per Week (Velocity)
* Issue Cycle Time
* Issue Reopen Rate
* Bug vs Feature Ratio
* MRs Merged Per Week (Throughput)
* MR Merge Time
* Time to First Review
* Review Comments Per MR
* MR Revert Rate
* Code Churn - High Frequency Files
* Commit Message Quality
* Unresolved Discussion Threads at Merge
* Review Comments Per 100 Lines
* Bus Factor
* Code Ownership Concentration
* Review Network Density
* Security Vulnerability Count
* Stale Issues Count
* Stale MRs Count
* Review Iteration Count
* PR/MR Review Coverage (%)
* Self-Merged MR Rate (%)
* Long-Lived Branch Count
* Active Contributors Per Week
* Dependency Update Lag (Average Days or "LibYears")
